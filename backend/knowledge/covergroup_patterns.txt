# Covergroup / functional coverage patterns (deep RAG)
# Curriculum map: https://chipverify.com/systemverilog/systemverilog-functional-coverage
# Prefer user RTL ports and real bins. Coverage ≠ proof of completeness if bins omit features.

## What functional coverage measures
- Which design features / scenarios tests exercised (not code coverage alone).
- CRV regressions: merge databases across seeds/tests to see union of hits.
- Limitation: missing coverpoints for unspecified features → false "100%" — mirror the spec.

## Covergroup structure
- `covergroup name;` … `endgroup` — create with `cg = new;` (or `new(this)` in UVM).
- `coverpoint var { bins ... }` — variables/expressions of interest.
- Multiple covergroups can sample same vars with different bin strategies.
- Name after feature: `cg_fifo_fill`, `cg_axi_resp`.

## Sampling triggers
- Event: `covergroup cg @(posedge clk);` or `@ (event e);`
- Explicit: `cg.sample();` after building a transaction / at monitor write.
- Conditional: `coverpoint mode iff (!rst_n == 0)` — skip during reset.
- `cg.stop()` / `cg.start()` to gate whole group around reset or idle.
- UVM: sample in monitor `write()` or analysis export; `option.per_instance = 1` for multi-agent.

## Binning vocabulary
- Explicit: `bins featureA = {0}; bins featureB = {[1:3]};`
- Array of bins: `bins common[] = {4:$};` — one bin per value in range.
- `bins reserve = default;` — catch-all for unlisted values (review if hit often).
- `illegal_bins` — must never hit (reserved opcodes); fail/report if hit.
- `ignore_bins` — legal but not interesting for closure %.
- Transition: `bins e2f = (0 => 15);` empty→full style for FIFO depth.
- Wildcard / others: use carefully; prefer named legal encodings from spec.

## Cross coverage
- `cross cp_a, cp_b;` — joint scenarios (opcode × status, addr_range × burst).
- Cross only meaningful pairs; huge crosses explode bins and slow merge.
- Ignore illegal crosses: `ignore_bins bad = binsof(cp_a) intersect {IDLE} && binsof(cp_b) intersect {ERR};`

## Options and reporting
- `option.per_instance = 1;` when type shared across agents.
- Name covergroups `cg_*` and coverpoints `cp_*`.
- Prefer a few named crosses; huge crosses explode bins and slow merge.
- Vendor switches required to dump UCIS/IMC/URG — ChipSutra Coverage page parses reports when provided.
- Merge multi-test DBs before declaring closure.

## Protocol-oriented coverpoints (signals must exist in RTL)
- AXI/AXI-Lite: AW/AR size/burst/len if present; WSTRB; BRESP/RRESP; back-to-back vs idle.
- APB: setup/access phases, PWRITE, PREADY waits, PSLVERR.
- AXI-Stream: TVALID/TREADY stalls, TLAST, TKEEP sparse vs full.
- FIFO: depth bins {0}, mid, full; push-when-full / pop-when-empty rejects; simultaneous push/pop.
- Interrupts: sticky vs pulse; mask on/off; clear-on-read if applicable.
- Counter: enable high/low; wrap; reset-during-count transition bins.

## Closing coverage holes (ChipSutra loop)
1. Rank holes worst-first from report.
2. Add directed sequence/task named after the hole; matching bin must be hittable.
3. Medium holes: tighten constraints / dist toward missing bins.
4. Re-sim deterministic seeds; compare before/after %.
5. Never invent ports — if signal absent, drop that coverpoint.

## Minimal covergroup sketch
```
covergroup cg_cnt @(posedge clk);
  cp_en: coverpoint enable { bins off = {0}; bins on = {1}; }
  cp_cnt: coverpoint count {
    bins zero = {0};
    bins mid  = {[1:14]};
    bins max  = {15};
  }
  x_en_cnt: cross cp_en, cp_cnt;
endgroup
```
Instantiate after reset release; sample every cycle or on enable edges.

## Verilator / OSS notes
- Covergroups in TB often compile; full UCIS feature set is vendor-specific.
- Pair functional bins with code/toggle coverage for OSS flows.
- ChipSutra Coverage-Hole Tests module consumes parsed hole lists → new stimulus.

## Anti-patterns
- Coverpoints on signals never driven → permanent holes / wasted bins.
- Enormous unconstrained crosses.
- Declaring 100% while illegal_bins never defined for reserved encodings.
- Sampling during reset without `iff` → polluted early bins.
- Inventing AXI coverpoints on a non-AXI DUT.
