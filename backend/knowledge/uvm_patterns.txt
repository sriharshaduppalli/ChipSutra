# UVM / SV testbench patterns (RAG). Prefer user RTL ports over invented names.

## Verilator-friendly randomized SV TB (DEFAULT)
- Prefer pure SystemVerilog over full UVM for local Verilator runs.
- Exact DUT port map: `dut_name dut ( .clk(clk), .rst_n(rst_n), ... );`
- Prefer **one random loop** with a golden model — not hardcoded Testcase 1..N lists.
- Driven TB signals: `reg`/`logic`. Include `$dumpfile`/`$dumpvars`/`$finish`.
- Clock MUST be: `always #5 clk = ~clk;`
- Golden MUST be independent (`expected`), never `exp = count + 1`.
- Keep ~45–70 lines. Forbidden: invented ports; chatty preamble; unrolled assert walls.

## Counter enable example (copy structure)
```systemverilog
`timescale 1ns / 1ps
module counter_rtl_tb;
  logic clk, rst_n, enable;
  logic [3:0] count;
  logic [3:0] expected;
  integer i, errors;
  counter_rtl dut (.clk(clk), .rst_n(rst_n), .enable(enable), .count(count));
  always #5 clk = ~clk;
  initial begin
    $dumpfile("counter_rtl_tb.vcd"); $dumpvars(0, counter_rtl_tb);
    errors = 0; void'($urandom(1));
    clk = 0; rst_n = 0; enable = 0;
    repeat (4) @(posedge clk); rst_n = 1; @(posedge clk);
    expected = '0;
    for (i = 0; i < 48; i = i + 1) begin
      enable = $urandom_range(0, 1);
      @(posedge clk); #1;
      if (enable) expected = expected + 1'b1;
      if (count !== expected) begin
        $error("mismatch"); errors = errors + 1;
      end
    end
    $finish;
  end
endmodule
```

## UVM (only when user asks)
- Real APIs only: config_db, get_next_item/item_done, start_item/finish_item.
- Forbidden: `.put()`, `.configure(vif)`, `cast(rhs)`, `driver.start(this)`.
- Randomize sequence_item fields that mirror DUT ports; constrain legal ranges.
